O avatar é um desenho de 64 por 64 feito só de formas simples (cabeça, ombros, olhos, um acessório), sorteado pelo nome do agente, então o mesmo nome dá sempre o mesmo rosto. As seis opções do criar agente são o mesmo nome com variações 0 a 5, e Regerar avatar escolhe outra. A mesma função vai para o Swift.

O Racky guarda cada agente em ~/Racky/agents e só gera a versão de cada CLI na hora de lançar. Nada é escrito em ~/.claude, ~/.codex ou ~/.config/opencode.
